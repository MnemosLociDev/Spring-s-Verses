# Tailwind Spacing Classes Reference

| Class | Type | Description |
|-------|------|-------------|
| `p-6` / `p-10` / `p-12` | Padding | Sets padding on all sides. Used for large section spacing. |
| `px-6` / `px-12` | Padding-X | Horizontal padding for containers. |
| `py-2.5` / `py-5` / `py-6` | Padding-Y | Vertical padding, often for buttons or table cells. |
| `mx-auto` | Margin-X | Centers an element horizontally. |
| `mb-4` / `mb-8` / `mb-12` | Margin-Bottom | Adds spacing below elements to create visual rhythm. |
| `mt-8` / `mt-24` / `mt-32` | Margin-Top | Spacing above large sections or footers. |
| `gap-4` / `gap-6` / `gap-10` | Flex/Grid Gap | Consistent spacing between children. |
| `space-y-4` / `space-y-6` / `space-y-10` | Space Between | Adds margin to children elements (vertical). |
| `pr-6` / `pl-3` | Padding-Right/Left | Specific side padding. |
| `inset-y-0` | Inset | Sets top and bottom to 0. |
