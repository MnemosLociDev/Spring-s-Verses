# Tailwind Typography Reference

| Class | Type | Description |
|-------|------|-------------|
| `text-brand` | Color | Applies the pinkish-red primary color. |
| `text-white` | Color | Solid white text. |
| `text-gray-100` ... `text-gray-600` | Color | Grayscale ramp for hierarchy. |
| `font-heading` | Font | Custom 'Space Grotesk' font mapped in `index.css`. |
| `font-black` | Weight | Extra heavy weight (900). |
| `font-bold` | Weight | Bold weight (700). |
| `font-medium` | Weight | Medium weight (500). |
| `text-xs` / `text-sm` / `text-base` | Size | Standard text sizes. |
| `text-4xl` ... `text-6xl` | Size | Large headlines. |
| `text-[120px]` | Size | Ultra-large hero text. |
| `uppercase` | Case | All caps. Used for buttons and metadata. |
| `tracking-tighter` | Tracking | Tight letter spacing for impact headlines. |
| `tracking-widest` | Tracking | Wide letter spacing for small metadata/labels. |
| `italic` | Style | Italicized text. |
| `line-clamp-2` | Clamping | Truncates text after 2 lines with ellipsis. |
| `leading-tight` / `leading-relaxed` | Leading | Custom line-height management. |
