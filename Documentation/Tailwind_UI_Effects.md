# Tailwind UI & Effects Reference

| Class | Type | Description |
|-------|------|-------------|
| `bg-surface-800` / `900` | Background | Layered dark backgrounds. |
| `bg-brand` | Background | Primary brand color background. |
| `bg-transparent` | Background | Transparent background for inputs. |
| `border` / `border-x` / `border-b` | Border | Basic border application. |
| `border-surface-700` | Border Color | Low-contrast border color for dark mode. |
| `border-brand` | Border Color | Highlights active or focused elements. |
| `border-dashed` | Border Style | Used for drag-and-drop or empty states. |
| `rounded-xl` / `2xl` / `3xl` | Radius | Moderate rounded corners. |
| `rounded-[2.5rem]` / `[4rem]` | Radius | Ultra-rounded "pill" or "fluid" corners for cards/modals. |
| `shadow-2xl` | Shadow | Large, soft shadow for page depth. |
| `shadow-inner` | Shadow | Inset shadow for inputs or containers. |
| `shadow-brand/20` | Shadow Color | Custom glow effect using brand color with opacity. |
| `blur-3xl` | Filter | Used for background glow blobs. |
| `backdrop-blur-md` | Filter | Frosty glass effect for navigation. |
| `opacity-20` / `opacity-90` | Opacity | Transparency control. |
| `selection:bg-brand` | Interaction | Custom highlighting color when selecting text. |
| `focus:outline-none` | Focus State | Removes default browser ring. |
| `focus:border-brand` | Focus State | Replaces default ring with brand color. |
| `hover:scale-105` / `active:scale-95` | Animation | Micro-interactions for buttons. |
| `transition-all` | Transition | Base for smooth property changes. |
| `duration-500` | Duration | Timing for transitions. |
| `group` / `group-hover` | Hierarchy | Triggers child style changes when parent is hovered. |
